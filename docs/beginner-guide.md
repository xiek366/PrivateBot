# PrivateBot 保姆级使用教程（Windows）

这份教程假设你**完全不懂编程**，只需要会解压文件、双击图标、在网页上点按钮。
按顺序照做即可，每一步都写清楚了「点哪里、填什么、怎么知道成功了」。

全程不需要打开命令行。

---

## 0. 先搞清楚三样东西

| 名字 | 是什么 | 谁提供 |
|---|---|---|
| **DeepSeek 密钥** | 让机器人会说话的"话费卡号"，按用量扣钱 | 你去 DeepSeek 官网申请 |
| **NapCat** | 让 QQ 能被程序控制的"中间人" | 你下载安装 |
| **PrivateBot** | 机器人本体，负责聊天、性格、记忆 | 直接用我们给你的压缩包 |

还有两个 QQ 号的概念，**千万别搞混**：

- **机器人自己的 QQ 号**：登录到 NapCat 里的那个号。机器人就"是"这个号。
- **能跟机器人聊天的 QQ 号**：你自己平时用的号。只有这个号能跟机器人说话，别人发了也不理。

---

## 1. 拿到 DeepSeek 密钥

1. 打开 <https://platform.deepseek.com>，注册 / 登录。
2. 左侧菜单找到「**API keys**」（有的版本叫「API 密钥」），点「**创建 API key**」。
3. 起个名字（随便填，比如 `privatebot`），点确定。
4. 这时会显示一串 `sk-` 开头的字符，**点复制按钮复制下来**。
   > 这串字符**只显示这一次**，关掉页面就再也看不到了。先粘贴到记事本里存着。
5. 左侧菜单找到「**充值**」/「**Top up**」，充一点钱（几块钱就够聊很久）。

**怎么确认成功**：你能在记事本里看到一串 `sk-` 开头的字符，并且账户里有钱。

---

## 2. 安装 NapCat 并登录 QQ

NapCat 是一个免费的开源项目，官方在 GitHub 上发布（搜 `NapCatQQ` 即可找到 Releases 页面）。

1. 下载 Windows 版压缩包（文件名通常带 `NapCat.Shell` 或 `Windows` 字样）。
2. 解压到一个**你不会随手删掉的目录**，比如 `D:\NapCat\`。
3. 运行目录里的启动文件（一般是 `NapCatWinBootMain.exe` 或 `.bat` 脚本）。
4. 第一次启动会打开一个网页版控制台（**WebUI**），
   按提示用**机器人自己的 QQ 号**扫码登录。
   > 手机上打开 QQ → 右上角「+」→ 扫一扫。
5. 登录成功后，在 WebUI 里找到「**网络配置**」，新增一个配置项：

   | 配置项 | 填什么 |
   |---|---|
   | 类型 | 「**WebSocket 客户端**」——重点是带「**客户端**」或「**反向**」字样的那一个，**不要选「WebSocket 服务器」** |
   | URL / 地址 | `ws://127.0.0.1:8080/onebot` |
   | Token / 访问令牌 | 先随便记一个好记的，比如 `my-token-123`，一会儿要填到 PrivateBot 里，**两边必须完全一样** |
   | 消息格式 | String（默认即可） |

6. 保存并**启用**这个配置项。
   > 不同版本的菜单文字可能略有差异。判断标准只有一条：
   > 这一项是让 NapCat **主动去连**某个地址（反向），而不是**等别人来连**它。

**怎么确认成功**：NapCat 的控制台里能看到 WebSocket 连接日志；
PrivateBot 那边会打印 `client connected role=...`。

> 小提示：QQ 对机器人账号有风控。用平时在用的老号比新注册的号稳定得多。

---

## 3. 解压并双击运行 PrivateBot

1. 把 `PrivateBot-win64.zip` 解压到一个**非系统盘**目录，比如 `D:\PrivateBot\`。
   > **不要放在 C 盘**，也不要在压缩包里直接双击运行——解压出来再运行。
2. 进入 `D:\PrivateBot\`，双击 **`PrivateBot.exe`**。
3. 会弹出一个黑色窗口。**这个窗口不要关**，关掉机器人就停了。
   最小化就行。

**怎么确认成功**：黑窗口里出现了一行行时间 + 文字的日志。

---

## 4. 填写配置向导

第一次运行（还没有配置文件时），除了黑窗口，还会弹出一个「**PrivateBot 首次配置**」小窗口，
里面只有 4 个格子：

| 格子 | 填什么 |
|---|---|
| **DeepSeek 密钥** | 第 1 步复制的那串 `sk-...` |
| **允许聊天的 QQ 号** | **你自己**的 QQ 号（不是机器人的号）。多个号用英文逗号隔开，例如 `123456,234567` |
| **OneBot 访问令牌** | 第 2 步在 NapCat 里填的那个 Token，**一个字都不能差** |
| **OneBot 端口** | 默认 `8080` 不用改；只有提示端口被占用时才改 |

填完可以点「**测试连接**」先验证密钥能不能用：

- 显示「[通过] 密钥可用」→ 可以保存了
- 显示「[失败] 密钥无效」→ 检查是不是复制时多带了空格
- 显示「[失败] 账户余额不足」→ 回 DeepSeek 官网充值

确认无误后点「**保存并启动**」。黑窗口里会开始刷日志，机器人就起来了。

> 只有第一次会弹这个窗口。之后每次双击 exe 都直接启动。

---

## 5. 测试聊天

1. 确认 NapCat 登录着机器人的 QQ，且那条 WebSocket 配置是「已启用」。
2. 用**你自己**的 QQ 号，加机器人的 QQ 为好友。
3. 发一句「你好」。
4. 几秒内应该收到回复。黑窗口里会同步打印收到消息、调用模型、发出回复的日志。

没反应？直接看第 6 节的对照表。

## 6. 常见错误对照表

| 现象 | 原因 | 怎么修 |
|---|---|---|
| 黑窗口一闪就没了 | 配置没填完就关了向导 | 重新双击 exe，把向导填完整再保存 |
| 提示「端口 8080 已被其它程序占用」 | 有另一个 PrivateBot 还在跑，或别的软件占了 8080 | 先去任务管理器结束多余的 `PrivateBot.exe`；不行就在向导里换端口，并把 NapCat 的 URL 改成同样的端口 |
| 提示「程序所在目录不能写入」 | 放在 C 盘且没有权限 | 把整个文件夹挪到 D 盘再运行 |
| 提示「密钥无效」 | 密钥复制错了 / 带了空格 / 已删除 | 回 DeepSeek 官网重新创建并复制 |
| 提示「账户余额不足」 | 没充值 | 去 DeepSeek 官网充值 |
| NapCat 显示连不上 / 一直重连 | 1. PrivateBot 没启动<br>2. 端口不一致<br>3. Token 不一致<br>4. URL 路径写错 | 按 1→4 顺序排查：先确认黑窗口在跑；再核对端口、Token；URL 必须是 `ws://127.0.0.1:8080/onebot` |
| 黑窗口显示 `auth failed` | Token 两边不一致 | 把 NapCat 的 Token 和向导里的令牌改成完全一样 |
| 黑窗口显示 `unexpected path` | URL 路径写错了 | 检查 URL 结尾是 `/onebot`，别漏掉 |
| 机器人不理我 | 你的 QQ 号不在白名单里 | 检查「允许聊天的 QQ 号」填的是不是你自己的号，用英文逗号分隔 |
| 回复很慢或没有回复 | 网络不通 / 密钥没余额 | 看黑窗口里带 `LLM 调用失败` 的日志行 |
| 全部都对但就是没回复 | NapCat 的配置项没启用 | 回 WebUI 确认那条 WebSocket 配置是「已启用」 |
| 电脑重启后没反应 | 需要重新启动 | 重新双击 exe；NapCat 也要重新启动并登录 |

## 7. 目录里都是什么

```
PrivateBot\
├── PrivateBot.exe        ← 双击这个启动
├── .env                  ← 配置向导生成的配置（可以手动改）
├── .env.example          ← 配置模板，别删，可以用它对照
├── data\
│   ├── personas\
│   │   └── default.yaml  ← 机器人的性格设定（可以改）
│   ├── style\
│   │   └── reference.txt ← 说话风格参考语料（可以改）
│   ├── sessions\         ← 聊天记录（自动生成）
│   ├── state\            ← 好感度 / 信任度等状态（自动生成）
│   └── memories\         ← 长期记忆（自动生成）
├── logs\
│   └── privatebot.log    ← 运行日志，出问题就把它发给开发者
└── _internal\            ← 程序内部文件，不要动、不要删
```

**可以放心改的**：`.env`、`data\personas\default.yaml`、`data\style\reference.txt`
**不要删的**：`_internal\`、`PrivateBot.exe`、`.env.example`
**想备份就直接复制一整个 `data\` 文件夹**，换电脑时覆盖回去即可。

---

## 8. 想让机器人更像你想要的样子

- **改性格**：用记事本打开 `data\personas\default.yaml`，按里面的中文注释改，保存后立即生效，不用重启。
- **改说话风格**：用记事本打开 `data\style\reference.txt`，一行一句往里加你喜欢的台词，保存后立即生效。
- **改时间之外的参数**：用记事本打开 `.env`，里面每一项都有中文注释说明。

> 用记事本保存时，如果弹出「另存为」对话框，**编码选 UTF-8**，不要选 ANSI，否则中文会变乱码。

---

## 9. 出问题了怎么求助

把这两样发出来：

1. `logs\privatebot.log` 这个文件
2. 黑窗口最后 20 行左右的截图

日志文件会按天自动切割、只保留最近 7 天，所以不用担心文件无限变大。

---

## 10. 怎么彻底卸载

1. 关掉黑窗口和 NapCat。
2. 删掉整个 `PrivateBot\` 文件夹。
3. 删掉整个 NapCat 的文件夹。
4. 不想要了就去 DeepSeek 官网删掉那个 API Key。

没有注册表残留，也没有后台服务。
